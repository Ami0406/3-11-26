ami & sai's world~ — video website

The original uploaded MP4 is included unchanged in media/ami-sai-world.mp4.
Open index.html locally to preview.

To make it public for an NFC tag:
1. Go to https://app.netlify.com/drop
2. Sign in or create a free Netlify account.
3. Drag the ENTIRE extracted folder (ami_sai_video_site) onto the page.
4. Netlify will publish it and give you a public https://...netlify.app address.
5. Open that address on a phone to test it, then write that exact address to your NFC tag.

Keep index.html and the media folder together. The video file must remain in media/.
